# Actividad 2.6 – Reglas de Asociación con Apriori

## Descripción
En esta actividad se utiliza el algoritmo Apriori para identificar productos que suelen comprarse juntos en una panadería, utilizando un dataset público obtenido desde Kaggle.

## Dataset
- **Nombre:** Bakery
- **Fuente:** Kaggle
- **Enlace:** https://www.kaggle.com/datasets/akashdeepkuila/bakery
- **Transacciones originales:** 9.465
- **Transacciones después de la limpieza:** 9.464

## Herramientas utilizadas
- Python
- Google Colab
- Pandas
- KaggleHub
- Mlxtend
- Matplotlib

## Desarrollo
1. Carga y exploración del dataset.
2. Limpieza y preparación de los datos.
3. Transformación a formato one-hot.
4. Aplicación del algoritmo Apriori.
5. Generación y comparación de reglas de asociación.
6. Interpretación de resultados y conclusiones.
