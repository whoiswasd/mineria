# Actividad 2.7 - Regresión Lineal

## Descripción

En esta actividad se aplican modelos de regresión lineal simple y múltiple utilizando Python y scikit-learn en Google Colab.

Se trabaja con tres datasets de Kaggle:

- **Breast Cancer Wisconsin:** regresión lineal simple para estimar perímetro y área.
- **FIFA 19:** regresión lineal múltiple para estimar la valoración general de jugadores.
- **Netflix Movies and TV Shows:** regresión lineal para analizar la duración de películas.

## Herramientas utilizadas

- Python
- Google Colab
- Pandas y NumPy
- Matplotlib y Seaborn
- Scikit-learn
- Statsmodels
- KaggleHub

## Contenidos

1. Carga y exploración de datos.
2. Análisis exploratorio (EDA).
3. Selección de predictores.
4. Entrenamiento de modelos.
5. Evaluación mediante R², MAE y RMSE.
6. Análisis de residuos, multicolinealidad y heterogeneidad.
7. Interpretación de resultados.
